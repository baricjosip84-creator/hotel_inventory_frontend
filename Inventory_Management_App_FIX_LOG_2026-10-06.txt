- This keeps exact-match semantics intact while no longer instructing users to enter a non-existent action code.

  - `event_domain`
  - `urgency`
  - `search`
  - `time`
  - `view`
- Controls hydrate directly from URL search parameters on render/remount.
- Control changes update URL search parameters with `replace: true`, preserving durable/shareable state without creating a browser-history entry for every keystroke/filter change.
- Existing `timeline_item_id` deep-link context is preserved when filter parameters change.
- Invalid/unavailable work-area values are removed from the URL instead of leaving a stale inaccessible filter.
